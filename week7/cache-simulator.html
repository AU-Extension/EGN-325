Cache simulator

Choose a cache size and a line size, run a pattern of memory reads, and watch every address split into tag, index, and offset as hits and misses add up.

How to use this interactive
  1. Pick a cache size, a line size, and a pattern of memory reads. The panel shows how each 8-bit address splits into tag, index, and offset.
  2. Press Step to follow one read in slow motion: the address is split, the index picks a line, the tags are compared, and the line turns green (hit) or red (miss). On a miss, a block rises from memory into the line.
  3. Press Play to watch the whole pattern, Pause to stop, and Back to undo a read. Drag the 3D view to turn it, and click a layer of the pyramid to learn about it.
  4. Change one setting at a time and run the same pattern again. That is how computer architects compare designs.
  5. Finish with the quick check at the bottom.
