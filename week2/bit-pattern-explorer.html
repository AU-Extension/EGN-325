Bit pattern explorer

Flip 32 bits in a 3D register and see the same pattern read as an unsigned number, a signed number, hexadecimal, a floating point value, and text.

How to use this interactive
  1. Click any bit to flip it between 0 and 1, or use a preset such as 0.1 or -1.
  2. Watch the right side: the same 32 bits read five different ways.
  3. Type a value in one of the boxes (a whole number, hexadecimal, a decimal number, or up to four letters) to see its bits.
  4. Turn on the float colors to see the sign, exponent, and fraction fields of a floating point number.

The register in 3D

Click a cube to flip that bit. Drag to orbit, scroll or pinch to zoom. The buttons below the 2D bits do the same thing.
