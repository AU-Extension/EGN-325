    Things to notice

    • The bits never change when you switch readings. Only the rule for reading them changes: unsigned, signed, float, or text.
    • Hexadecimal is a shorthand: each hex digit stands for exactly four bits, so 32 bits are 8 hex digits.
    • For a signed number the leftmost bit decides the sign. Flip every bit and add 1 to change the sign (two’s complement).
    • Try the 0.1 preset: the exact stored value is a little more than 0.1, because 0.1 has no exact binary form.
    How to use this interactive
    1. Click any bit to flip it between 0 and 1, or use a preset such as 0.1 or -1. A lit green bit is a 1; a dark bit is a 0.
    2. Watch the panel: the same 32 bits read five different ways.
    3. Type a value in one of the boxes (a whole number, hexadecimal, a decimal number, or up to four letters) to see its bits.
    4. Turn on the float colors to see the sign, exponent, and fraction fields of a floating point number.
    5. Pick a guided explanation and press Run, or step through it.
