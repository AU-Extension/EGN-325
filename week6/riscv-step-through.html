Things to notice

      
    
        
  • Every instruction names its registers by number: rs1 and rs2 are read (blue on the board), rd is written (red).
    • 
        
  • lw and sw add a 12-bit offset to a base register to get the address. Words are 4 bytes, so the next word is 4 addresses later.
    • 
        
  • jal saves pc + 4 in ra before it jumps, so ret can come back to the line after the call.
    • 
        
  • li, la, mv, and ret are pseudo-instructions: compare the Source and Basic columns to see what RARS really runs.
    • 
      

    


    

      How to use this interactive
      
    
        
  1. Pick a sample program. Each one is valid RV32I code that also runs in RARS, so you can paste it there and compare.
    2. 
        
  2. Press Step forward to run one instruction. The narration explains it, the board shows which registers are read (blue) and written (red), and values travel between the registers, the ALU, and memory.
    3. 
        
  3. Use Step back to undo, Play to run at reading speed (the speed slider makes it faster or slower), and Reset to start over. Rotate the board and click any register chip or memory word to see its value.
    4. 
        
  4. Turn on Predict before you step to guess the new register value, or whether a branch is taken, before each instruction runs.
    5. 
        
  5. Edit the code (or write your own) and press Assemble. Error messages tell you the line and what is wrong.
