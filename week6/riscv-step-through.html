RISC-V step-through simulator

Run real RISC-V assembly one instruction at a time and watch the registers, memory, and program counter change.

How to use this interactive
  1. Pick a sample program. Each one is valid RV32I code that also runs in RARS, so you can paste it there and compare.
  2. Press Step forward to run one instruction. The caption explains it, the 3D model shows which registers are read (blue) and written (red), and values travel between the registers, the ALU, and memory.
  3. Use Step back to undo, Play to run at reading speed, and Reset to start over. Rotate the 3D model and click any register cube or memory block to see its value.
  4. Edit the code (or write your own) and press Assemble. Error messages tell you the line and what is wrong.

Edit the code

Supported: add, sub, and, or, xor, slt, sll, srl, addi, andi, ori, xori, slli, srli, lw, sw, lui, auipc, beq, bne, blt, bge, jal, jalr, ecall, and the pseudo-instructions li, la, mv, j, ret, nop, beqz, bnez. System calls: a7 = 1 print integer, 4 print string, 10 exit, 11 print character. Comments start with #.
