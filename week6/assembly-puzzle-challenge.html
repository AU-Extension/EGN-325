Assembly puzzle challenge

Predict what short RISC-V programs print, choose the missing instruction, and find the bug in code an AI assistant wrote.

How to use this challenge
  1. Ten puzzles worth 10 points each: predict what a program prints, choose a missing instruction, and find the bug in code an AI assistant wrote.
  2. Read the numbered listing, then pick one answer. The feedback explains the right answer and what is wrong with your choice.
  3. After you answer, press Step forward or Play under "Run it" to watch the program execute in the 3D register bank. For bug puzzles you can run the buggy version and the fixed version and compare.
  4. All programs are valid RV32I for RARS, so you can paste any of them into RARS to check. Try again gives you new numbers.
