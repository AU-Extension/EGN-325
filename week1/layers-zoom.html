    Things to notice

    • The action stays the same all the way down; only its form changes, from a formula you type to a single instruction to voltages on wires.
    • The top layers are software and the bottom layers are hardware inside the processor chip. The instruction set is where the two meet.
    • Each layer only needs to know the layer right below it. That is abstraction, and it is why an app developer never thinks about transistors.
    • Switch actions and compare: the application and operating system layers change a lot, while the bottom layers look almost the same for every action.
    How to use this interactive
    1. Choose an everyday action at the top, such as adding two numbers in a spreadsheet.
    2. Press Run to follow that action from the app down to the transistors, or use Step and Step back to go at your own pace. The speed slider makes Run faster or slower.
    3. Orbit the 3D board and click any layer, or use the ladder in part 2, to jump to a layer.
    4. Read what the same action looks like at that layer and which week of the course covers it.
    5. Try every action, then answer the six "Which layer?" questions at the bottom.
