How to use this challenge
  1. Read each Bay-4 program and question, then pick one answer. There are 10 rounds worth 10 points each.
  2. After you answer, read the feedback: it explains why the right answer is right and what went wrong with the other choices.
  3. Press Play or Step forward under "Watch it run" to see the program move through the 3D datapath, one instruction at a time, with the trace table filling in.
  4. Keep the instruction set card open if you need it. At the end you get a score out of 100; Try again gives you new numbers.
Bay-4 instruction set card
OpcodeInstructionWhat it does
0000NOPNothing, go to the next instruction
0001LDA nA = n
0010LDB nB = n
0011ADDA = A + B (mod 16), set Z
0100SUBA = A - B (mod 16), set Z
0101ANDA = A AND B, set Z
0110ORA = A OR B, set Z
0111OUTShow A on the output display
1000JMP aPC = a
1001JZ aIf Z = 1, PC = a; otherwise PC + 1
1111HLTStop

Every instruction except JMP, a taken JZ, and HLT ends with PC = PC + 1. ALU operation codes: 00 ADD, 01 SUB, 10 AND, 11 OR. Z = 1 when an ALU result is 0000.
