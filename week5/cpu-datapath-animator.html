CPU datapath animator

Watch the Bay-4 processor run a program one phase at a time: fetch the instruction, decode it into control signals, and execute it.

How to use this interactive
  1. Pick a sample program, or write your own in the program box (one instruction per line) and press Load program.
  2. Press Step forward to move through fetch, decode, and execute. Watch the yellow data packets travel on the buses; red blocks are active in that phase. Step back undoes a phase.
  3. Read the explanation and the control signals the decoder turns on for the current instruction.
  4. Rotate the 3D board and click any block to learn what it does, or switch to the 2D diagram. Use Next instruction or Play to go faster, then try the self-check.

Write or edit the program

One instruction per line: NOP, LDA n, LDB n, ADD, SUB, AND, OR, OUT, JMP a, JZ a, HLT (n and a are 0 to 15). Text after # is a comment.

Instruction ROM

Each word is 8 bits: a 4-bit opcode (what to do) and a 4-bit operand (a number or a jump address). The highlighted row is where the PC points.
